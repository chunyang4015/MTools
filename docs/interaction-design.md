## 快捷键

| 按键 | 位置 | 行为 |
|------|------|------|
| 全局快捷键（按下） | 窗口隐藏时 | 唤起搜索栏 + 剪贴板检测 |
| 全局快捷键（按下） | 搜索栏 | 隐藏窗口 |
| 全局快捷键（按下） | 工具面板 | 回到搜索态（Tab 保留） |
| Esc | 搜索栏 | 隐藏窗口 |
| Esc | 工具面板 | 回到搜索态（Tab 保留） |

全局快捷键默认 Alt+Space，通过设置工具可修改，持久化到 `~/Library/Application Support/com.mtools.app/config.json`。支持 Alt/Cmd/Ctrl/Shift + 任意字母、数字、F键、空格。

工具直达快捷键：每个支持的工具（如翻译命名）可在自身设置面板中录入独立快捷键。按下后直接打开对应工具面板，跳过搜索流程。通过 `register_tool_shortcut` / `unregister_tool_shortcut` Rust 后端命令注册，持久化到配置文件 `tool_shortcuts` 字段。前端通过监听 `open-tool-direct` 事件调用 `openTool(toolId)` 实现。

| ↑ ↓ | 搜索结果 / 剪贴板结果 | 高亮上下移动（循环） |
| Enter | 搜索结果 / 剪贴板结果 | 打开高亮的工具/应用 |
| Backspace | 非输入框焦点 | 拦截，防止 webview 后退导航 |

## IME 组合输入

中文等输入法在候选词阶段不应触发搜索或快捷键：

- `compositionstart` → 设 `isComposing = true`，阻止 `input` 事件触发搜索
- `compositionend` → 设 `isComposing = false`，此时才执行搜索；设 `compositionJustEnded = true`
- `keydown` 中检查 `e.isComposing || isComposing`，组合中所有按键被忽略
- `compositionJustEnded` 标志防止确认候选词的 Enter 穿透到搜索结果选择（WebKit 中 `compositionend` 先于 `keydown` 触发）

## 窗口大小

| 场景 | 高度 | 模式 |
|------|------|------|
| 空搜索栏 | 58px | 立即 |
| 搜索/剪贴板结果 | 58 + N×58px | 防抖 30ms |
| 工具面板 | 560px | 立即 |
| 无匹配结果 | 58 + 40px | 防抖 30ms |

防抖策略：搜索输入时 30ms 延迟合并连续 resize IPC；视图切换（打开/关闭工具、初始化）立即执行，高度未变时跳过。

## 状态详情

### 状态 1：空白搜索栏

- 窗口高度 58px，白色圆角（10px），透明背景
- 唤起时自动读取剪贴板，匹配则进入剪贴板检测结果

### 状态 1.5：剪贴板检测结果

- 复用搜索结果的 result-item 样式，描述文字为工具返回的检测描述
- 多个工具可同时匹配，全部列出
- **翻译工具优先置顶**：当多个工具同时匹配时，翻译工具排在第一位，方便快速按 Enter 打开
- 用户输入关键词时隐藏剪贴板结果，清空后恢复

### 状态 2：搜索结果列表

- 窗口高度动态：58 + N×58px（N = 匹配项数，最多 10）
- 混合展示内置工具（最多 5 个）和系统应用（最多 5 个）
- 第一项自动高亮，↑↓ 循环切换，Enter 打开

### 状态 3：工具面板

```
┌──────────────────────────────────────────────┐
│ {} JSON 格式化  🔐 Base64  × │ ... │  ← Tab栏│
├──────────────────────────────────────────────┤
│                                              │
│            工具内容区                         │
│         (工具自定义 UI)                       │
│                                              │
├──────────────────────────────────────────────┤
│  ⊞格式化  ⊟压缩  │  ⎘复制  ✕清空  │ 过滤输入│  ← 底部工具栏（可选）
└──────────────────────────────────────────────┘
```

- 窗口固定高度 560px
- Tab 栏（40px）：已打开的工具 Tab，当前高亮，每个有 × 关闭按钮
- 内容区（flex:1）：工具自身 UI，切换 Tab 时通过容器显隐
- 底部工具栏（44px，可选）：按钮、分隔线、输入框
- 打开/切换 Tab 时 RAF 聚焦工具内第一个可输入元素

## Tab 系统

- 最多同时打开 5 个 Tab，超出时移除最早的
- 再次打开同一工具时切换到已有 Tab，不重新渲染
- 关闭当前 Tab 后自动切换到相邻 Tab；无 Tab 时返回搜索态

## 焦点管理

| 场景 | 行为 |
|------|------|
| 打开工具 | blur 搜索框 → RAF 聚焦工具首个输入框 |
| 切换 Tab | RAF 聚焦新 Tab 首个输入框 |
| 返回搜索 | 聚焦搜索框 |
| 窗口失焦 | 自动隐藏 |

## 窗口特性

- frameless、transparent、alwaysOnTop
- `macOSPrivateApi: true`（圆角 + 透明必需）
- 初始 `visible: false`，由全局快捷键控制显隐
- 不显示在 Dock 栏（`ActivationPolicy::Accessory`）
- 拖动：点击任意非交互区域即可拖动（`mousedown` + `startDragging()`）
- 窗口宽度：屏幕宽度 × 52%（最小 600px），Rust 端 `OnceLock` 缓存
